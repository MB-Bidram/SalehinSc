SalehinSc update instructions
=============================

1. Back up the repository and the complete data/ directory.
2. Copy application, Worker, workflow and documentation updates into the live
   checkout. Keep the live data/ directory; never replace it with sample data.
3. Remove retired teacher-QR artifacts before the first deploy. From the live
   checkout, run:

     npm run cleanup:retired-teacher-qr
     git rm -f --ignore-unmatch teacher.html

   The cleanup command removes only the obsolete teacher/index.html and
   tools/staff-qr-maker.html files (and empty folders). The git rm removes the
   formerly published root redirect if it is still tracked. Do this before
   generating/downloading the new private teacher.html. If you already have a
   newly generated private teacher.html, move it outside the repository first.
4. Keep the new local primary-teacher file outside Git. It is named teacher.html
   and is ignored by .gitignore. The Pages deployment workflow also excludes it.
5. Deploy the Worker and static Pages app. Keep GITHUB_TOKEN only in the
   Cloudflare Worker secret.
6. For the one-time transition from the previous shared teacher access, enter once
   using the currently valid access method. In the roster select
   “ساخت / تعویض فایل خصوصی دبیر”. Confirm the rotation and save the downloaded
   teacher.html in a private folder. This invalidates the old credential. No new
   teacher QR is generated.
7. From then on open the local teacher.html file for teacher access.
8. Student QR codes are unchanged. They remain individual student credentials.

Do not commit, email, upload or share teacher.html. Anyone with a copy can act
as the primary teacher until the credential is rotated. The file contains no
GitHub PAT; publishing goes through the Cloudflare Worker.
